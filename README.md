# Proyecto Limpieza Web

Interfaz web en React + Vite + TypeScript para solicitar servicios de limpieza a domicilio.

## Comandos

```bash
npm install
npm run dev
```

## Vistas principales

- `/` Inicio
- `/servicios` Servicios
- `/reserva/paso1` Tipo de limpieza
- `/reserva/paso2` Frecuencia y horario
- `/reserva/paso3` Detalles del servicio
- `/reserva/paso4` Fotos y notas
- `/reserva/paso5` Datos de contacto
- `/reserva/paso6` Revisión final
- `/confirmacion` Confirmación
- `/panel` Panel interno de la empresa
